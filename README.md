# 📈 Linear Regression Using Machine Learning

## 📌 Project Overview
Linear Regression is a supervised machine learning algorithm used to predict a continuous numerical value based on the relationship between independent and dependent variables.

This project demonstrates how to build a Linear Regression model using Python and Scikit-learn to analyze data, train a model, and make predictions.

## 🎯 Objectives
- Understand the concept of Linear Regression.
- Train a machine learning model using sample data.
- Predict numerical values based on input features.
- Visualize the relationship between variables.
- Learn the basic machine learning workflow.

## ✨ Features
- Data loading and preprocessing.
- Model training using Linear Regression.
- Prediction on new input data.
- Model performance evaluation.
- Data visualization using graphs.

## ⚙️ Algorithm
Linear Regression models the relationship between input and output using the equation:

\[
y = mx + c
\]

Where:
- `y` – Predicted output.
- `x` – Input feature.
- `m` – Slope of the regression line.
- `c` – Intercept.
